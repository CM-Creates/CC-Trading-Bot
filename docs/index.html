How Hermes trades

Hermes runs on the WAT framework: workflows for judgment, an agent for orchestration, and deterministic tools for anything that touches money. The rule that matters most is the last one below.

01 WORKFLOWS

Written playbooks, not vibes

Pre-market research, midday risk checks, and end-of-day review are markdown SOPs: the same brief you'd hand a human trader.

02 AGENT

Judgment, kept in its lane

Claude reads the rulebook, weighs the research, and decides what to do next. It reasons. It does not touch the order API directly.

03 TOOLS

Deterministic execution

Every order, stop, and account read runs through a plain Python wrapper around Alpaca's API. Same input, same output, every time.

The rulebook

A fixed set of hard rules governs every decision. Here are the ones that most often decide a trade. None of them bend for a good story.

  1. No options. Not ever, not "just this once."

  2. Max 5 to 6 open positions at any time.

  3. No single position larger than 20% of equity.

  4. A 10% trailing stop on every position, placed as a real order, not a mental note.

  5. Unrealized loss past -7% closes the position immediately, no hoping for a bounce.

  6. Max 3 new trades a week. A quiet week can be the correct week.
